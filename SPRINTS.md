# Sprints

## Sprint 0 · Synthetic demonstration
Acceptance requires desktop and mobile browser evidence, missing-field behavior, a matching receipt, an unverified receipt case and an exportable evidence report. Docker Compose and GitHub Actions carry the repeatable runner.
The initial GitHub Actions browser run passed all three cases and uploaded the synthetic evidence.

## Sprint 1 · Agency pilot
Acceptance requires a signed-off scope, a named confirmation contact and an agency-reviewed evidence report with a retest record when applicable.

Use the [pilot run sheet](PILOT.md) to capture scope, the five-submission allowance, destination evidence, and the outcome of one retest.
